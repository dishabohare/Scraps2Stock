Scraps2Stock — Surplus Food Redistribution Platform:

Scraps2Stock is a web application that connects street food vendors with mandis, farms, and cold storages where surplus but edible raw materials are available at low cost. The main aim is to reduce food waste and lower the daily raw material cost for vendors.

Problem:
Every day, a large quantity of vegetables, fruits, and raw materials go to waste in mandis and farms. At the same time, street vendors buy the same items at high prices. There is no direct system connecting these two sides.

Solution: 
Scraps2Stock allows suppliers to post their surplus stock, and vendors can place bids to purchase it at lower prices. The platform also includes AI-based matching and spoilage prediction to minimize waste.

Core Features: 
<img width="861" height="709" alt="Features" src="https://github.com/user-attachments/assets/9941c001-89e8-4cd8-89b2-0fc9ec7cbe07" />
Suppliers can post surplus stock
Vendors can view live listings and place bids
Reverse bidding system for best price discovery
AI-based matching according to vendor needs
Spoilage prediction to reduce waste
Vendor dashboard with monthly spend and order overview
Secure login and authentication using JWT

Tech Stack:
Frontend: React, Tailwind CSS
Backend: Spring Boot
Database: MySQL
Authentication: JWT

How to Run the Project
To run the backend: clone the repository
open it in your IDE
run the Spring Boot application
To run the frontend: go to the frontend folder
run npm install
run npm start
